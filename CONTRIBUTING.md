# Contributing to Thymble Server

Thanks for your interest. The project is in early development, so the best way to help right now is to open an issue to discuss an idea before writing code.

## Developer Certificate of Origin (DCO)

Every commit must be signed off, certifying that you wrote the change or otherwise have the right to submit it under this project's license (AGPL-3.0). The full text is at https://developercertificate.org/.

Sign off by adding `-s` when you commit:

```bash
git commit -s -m "Describe your change"
```

This adds a line like:

```
Signed-off-by: Your Name <you@example.com>
```

Use your real name and an email you can be reached at. Pull requests with unsigned commits can't be merged. To sign off commits you already made: `git rebase --signoff main`.

## Ground rules
- **No secrets** in commits, issues, or logs. Use placeholder values.
- **Connectors welcome.** List and retailer connectors are a great first contribution once the connector interfaces land. Please respect each service's API terms; connectors must not get around bot protection or store data a provider's terms forbid.
- Be kind. Assume good intent.
